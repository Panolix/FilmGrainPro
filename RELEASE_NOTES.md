# FilmGrainPro v2.3.3

Small naming cleanup. The window title no longer calls the app a "film grain
simulator" — it is simply **FilmGrainPro** everywhere it is visible.

## Changed

- Window title on the taskbar, Alt+Tab and the title bar is now `FilmGrainPro`
  instead of `FilmGrainPro - Film Grain Simulator`.
- No other changes: grain rendering, the film database, export formats and
  settings are identical to v2.3.2.

## Upgrading

If **Film Grain Generator** (v2.1.0) still appears in your Start Menu or
Settings → Apps, it is a separate older install. Uninstall it once; it is not
removed automatically by this or any later release.

Uninstall **FilmGrainPro** before installing this build, so the previous
executable is not left behind in the install folder.
